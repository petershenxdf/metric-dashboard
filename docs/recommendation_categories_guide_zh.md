# 六类人工复核评分

当前实现依据 Dashboard_Active_Learning_LaTeX.zip。原来的八类规则推荐、综合优先级和 DeepSeek 解释流程已移除。

| 类别 | 高分意味着什么 | 建议人工反馈 |
| --- | --- | --- |
| Cluster Assignment Conflict | 最近的正常比较点与当前分组不一致 | 语义类型 |
| Label Coverage Gap | 有局部数据支撑，但离已有语义标签较远 | 语义类型 |
| Weak Group Reachability | 到人工支持的正常参考点的完整扩展路径连接较弱 | 语义类型，必要时正常/异常 |
| Local Sparsity | 附近数据支撑较少 | 正常、异常或不确定 |
| Known-Outlier Similarity | 与人工确认异常相似，且需要检查是否为局部匹配 | 正常、异常或不确定 |
| Model Instability | MinPts 相邻设置的完整模型重跑改变了分组成员或异常状态 | 正常/异常或语义类型 |

每个点有六个独立分数。显示数字是本轮该类别合格候选中的中位秩百分位，
不是出错概率或异常概率，也不能相加得到总分。原始分数相同时百分位相同；
全部并列时都为 50，并显示 All tied。缺少必要信息显示 NA，不以零代替。

覆盖类别先检查局部支撑；异常相似度需要人工确认异常，模型自己预测的异常不能充当参考。
可计算的高相似度即使未通过局部匹配，也保留分数，只是不推荐。
弱可达性使用完整扩展路径的瓶颈，不使用到参考点的直接距离。
模型不稳定性比较每次运行的实际分组成员集合，不比较组号。

默认冲突分数须大于零；覆盖须达到第 75 百分位；
弱可达性、局部稀疏和不稳定性须原始分数大于零且达到第 75 百分位；
已知异常相似度须达到第 75 百分位并通过局部匹配。
这些是项目默认策略，不是已被实验证明最优的参数。

## 使用矩阵

点击列头或 Sort by 排序；NA 在升序和降序都排最后。状态、当前组别和 ID 搜索始终限制可见行。
多个分数条件支持 Match ALL 和 Match ANY，还可单独筛选 NA。
Recommendable 开关会同时应用类别的推荐条件。筛选不会重算百分位或改变颜色。

点击行、色块或散点图选点，查看原因、比较点、原始值和公式。颜色保持模型组别含义；
选择、推荐和比较分别用不同描边表示。批量推荐不重复选择相同模型特征的记录。

人工标签支持语义类型、Normal、Outlier、Unsure。Unsure 保存本次困难并延后一轮，
不成为任何已确认参考。提交后模型、矩阵和队列一起更新，保留当前选中 ID。
有明确模型分组成员变化的已标注点可出现在 Needs re-review 中。

旧会话需点击升级按钮创建新轮次；旧数据、模型快照和标签历史保留。
具体公式与实现选择见 [设计说明](modules/active_learning/design.md)。
同名 PDF 是升级前的历史材料，不代表当前实现。
